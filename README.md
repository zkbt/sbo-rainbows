# 🌈🔭⛰️ sbo-rainbows 🌈🔭⛰️

This repository is a place to collect conversations and experiments surrounding time-series slitless spectroscopy at Sommers-Bausch Observatory. 

## Issues + Projects
Let's propose and track things we want to do as [Issues](https://github.com/zkbt/sbo-rainbows/issues). If we want to be super fancy we can organize these into GitHub [Projects](https://github.com/zkbt/sbo-rainbows/projects), but simply posting and responding to Issues is probably enough. 

## Code 
If we have shared code that might be useful for working with data or planning observations at SBO, let's please build it into a fun little package here. Feel free to commit and push any `.py` files you want, but if you're going to push a `.ipynb`, it's probably best to clear all its outputs before committing it, to prevent the repository from getting too clogged up.
